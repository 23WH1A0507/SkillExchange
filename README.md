# Skill Exchange

Skill Exchange is a web platform that connects learners and mentors for peer-to-peer skill sharing, collaboration, and knowledge exchange.

## Features

* User registration and login
* User profiles and skill showcase
* Skill-based user discovery
* Mentor/Learner connection requests
* Ratings and feedback system
* Reporting and moderation features
* Responsive user interface

## Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MySQL
